# Презентация Task Manager (около 1 минуты, 2 докладчика)

## Task Manager

Task Manager. Планировщик задач на Vue 3.

«Добрый день! Мы представляем Task Manager, планировщик задач на Vue 3. Он помогает планировать дела по дням, неделям и месяцам.»

- Неделя в виде календаря
- Страница каждого дня
- Три месяца на одном экране
- Цели месяца и года
«На странице недели задачи видны как в календаре, а по клику можно открыть любой день отдельно. На странице месяцев видны сразу три: предыдущий, текущий и следующий. Для каждого можно задать цель, а также цель на год.»

- Vue 3 + Vue Router
- Данные: localStorage → бэкенд
- Отдельный слой хранения
«Внутри мы используем Vue Router для страниц и отдельный слой хранения данных. Сейчас данные лежат в localStorage, но при переходе на сервер придётся поменять всего один файл.»

- Создание, редактирование, удаление
- Поиск и фильтры
- Статусы и приоритеты
- Статистика выполнения
«В приложении можно создавать, редактировать и удалять задачи, искать их, фильтровать по статусу и приоритету и следить за статистикой выполнения. Спасибо за внимание, будем рады вопросам!»
